A notification is a "toast" the system shows in a corner of the screen, even when your window is hidden or in the background. It uses WinRT on Windows and the desktop's notification service on Linux. Available since 0.3.0.

1. Your first notification

One call, from anywhere in your code:

app.notify(Notification.of("Export finished", "report.pdf is ready"));

The title is required, the body is optional. Both have length limits (256 and 1024 characters).

2. Reacting to the user

A notification can do something when the user clicks it, offer buttons, and even include a text field:

app.notify(Notification.of("Export finished", "report.pdf is ready")
        .withOnClick(() -> window.focus())
        .withButton("Open", () -> open())               // up to 5 buttons
        .withReply("Send", "Reply", text -> send(text)))  // a text field: Windows only
    .thenAccept(shown -> { /* false: the system did not show it */ });
  • withOnClick runs when the user clicks the notification itself. Bringing your window to the front with window.focus() is the usual answer.
  • withButton(label, action) adds a button, up to 5.
  • withReply(buttonLabel, placeholder, handler) adds a text box with a send button; the handler gets the text. Windows only.
  • The returned future says whether the system showed the notification.

Callbacks run on the UI thread while the app runs.

3. Only when it helps

If the user is already looking at your window, a toast is noise. Check window.isFocused() (since 0.3.1):

if (!window.isFocused()) {
    app.notify(Notification.of("New message", "Ada: lunch at noon?").withOnClick(window::focus));
}

4. Platform notes

  • On Windows the first call registers your appId as the display name under HKCU\Software\Classes\AppUserModelId (nothing is installed). The future is false if the user turned notifications off.
  • On Linux the future is false when there is no notification service.

Treat false as "the user will not see it", and show the information in your own window as well if it matters.

5. From the page

To let trusted pages do it, call window.enableNotifications(app) before the page loads, then:

await jolt.notify(title, body, {
  onclick,
  buttons: [{ label, onclick }],
  reply: { label, placeholder, onreply }
});

At most 5 notifications per 10 seconds per window.
