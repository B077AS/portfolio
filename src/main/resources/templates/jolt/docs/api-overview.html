A quick lookup of the main types and calls, with a link to the page that explains each. Everything here is in the package io.github.b077as.jolt unless noted.

Application and options

CallWhat it does
Application.create(AppOptions)Builds the app on the matching backend.
AppOptions.of(id)App id, data folder. withDataDirectory, withQuitWhenLastWindowClosed, withQuietNativeLogs.
app.run(onStart) / app.quit()Run the event loop (blocks) / stop it.
app.createWindow(WindowOptions) / app.windows()Open a window / list open windows.
app.dispatch, app.submit, app.isUiThreadRun on the UI thread; check the thread.
app.openExternal(URI)Open an http, https or mailto address in the user's program.
app.notify(Notification)System notification. Notifications
app.isTraySupported(), app.createTray(icon, tooltip), app.autostart()Tray and autostart
SingleInstance.acquire(...)Allow one copy per user. Tray
app.clipboard()Read and write text, HTML, images and files. Clipboard
app.urlSchemes(), UrlSchemes.findUrl(args, scheme)Open the app for myapp:// links. Custom links
app.setJumpList(JumpList), app.supportsJumpList()Tasks and categories on the taskbar or launcher icon menu. Taskbar

WebWindow: showing a page

CallWhat it does
loadHtml(html)Show an HTML string.
loadResources(AppResources, [handler], [ResourceOptions])Show a multi-file page; optional Java request handler. Serving files
AppResources.classpath(base) / directory(path)Files from the jar / from a folder.
loadUrl(url)Show an address (trusted origins only).
ready()Future that completes when the web view has started.

WindowOptions

Immutable; start from WindowOptions.defaults(). Methods: withTitle, withSize, withMinSize, withIcon, withTitleBarScheme, withBackgroundColor, withMaximized, withCentered, withVisible, withFrameless, withOwner, withDevTools, withSecurity. See Window look and placement.
