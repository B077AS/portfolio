## About

This is the source for [williamsolari.com](https://williamsolari.com) - a personal portfolio site built with Spring Boot and Thymeleaf, listing my projects and how to get in touch.

## Tech stack

- **Java 25** / **Spring Boot 4.1** - Spring MVC, Spring Security, Spring Mail, Bean Validation
- **Thymeleaf** - server-rendered templates, with the layout dialect for shared page structure
- **Vanilla CSS/JS** - no frontend framework; [Material Design Icons](https://materialdesignicons.com/) and [IBM Plex](https://fontsource.org/fonts/ibm-plex-sans) fonts, bundled at build time via a Maven-driven npm step

## Running locally

Requirements: **Java 25** and Maven (or the bundled `mvnw`).

```bash
./mvnw spring-boot:run
```

The app starts on `http://localhost:8080`.

## Jolt showcase site (second website, same app)

`jolt.williamsolari.com` is served by this same Spring Boot application, with its own design, SEO, robots.txt and sitemap.

- Layout: one application, three areas, on both the Java and the resource side.

  | Area | Java (`com.williamsolari.*`) | Templates | Static files |
  |------|------------------------------|-----------|--------------|
  | core | `core.config`, `core.web` (host routing, error page) | none | none |
  | portfolio (`williamsolari.com`) | `portfolio.{controller,model,service,util}` | `templates/portfolio/` | `static/portfolio/`, data in `portfolio/projects.json` |
  | jolt (`jolt.williamsolari.com`) | `jolt.{controller,model,service}` | `templates/jolt/{layouts,fragments,pages,docs}/` | `static/jolt/`, JSON-LD shapes in `jolt/jsonld-*.json` |

- `core.web.SiteRoutingFilter` looks at the request host and forwards every request internally to the same path under the site's prefix: `/jolt` for a Jolt host, `/portfolio` for everything else
  (so `jolt.williamsolari.com/docs` is `JoltController` at `/jolt/docs`, `/css/jolt.css` is `static/jolt/css/jolt.css`, and `williamsolari.com/css/base.css` is `static/portfolio/css/base.css`). The prefixes are never public (404 if requested).
- robots.txt and sitemap.xml are per site: the portfolio's are plain files (`static/portfolio/robots.txt`, `sitemap.xml`); Jolt's are generated by `JoltSeoController` (`/jolt/robots.txt`, `/jolt/sitemap.xml`, built from the docs list) so they list every doc page with its `lastmod`.
- Pages: `templates/jolt/pages/` (home, parsel, changelog, doc, error) on `layouts/layout.html`. Documentation bodies are one fragment per page in `templates/jolt/docs/<slug>.html`; the list and descriptions are in `JoltDocs`.
- Config (`application.properties`): `site.jolt.hosts`, `site.jolt.base-url`, `site.jolt.version-url` (the Jolt version shown on the site is the latest GitHub release, refreshed hourly; there is no version property). `server.forward-headers-strategy=framework` makes the app trust `X-Forwarded-*` from nginx.
- Local preview: run the app and open `http://jolt.localhost:8080` (browsers resolve `*.localhost` to your machine, no hosts-file change).
- nginx: proxy both server names to the app and keep the original host: `proxy_set_header Host $host;` plus `X-Forwarded-Proto` and `X-Forwarded-Host`. The certificate must cover `jolt.williamsolari.com`.
